# MLK Tāmēšanas Aģenta arhitektūra

PDF rasējumi → nolasīta ģeometrija ar avotu → cilvēka apstiprinājums → konstrukciju receptes (karkass, SIP, CLT) → deterministiski daudzumi → privātas cenas un darba normas → Excel tāme un klienta piedāvājums.

## Pašreizējais statuss
Tikai manuāli ievadītas sienas demonstrācijas aprēķins. Statņu skaits un izolācijas tilpums ir aptuveni. Nav PDF lasītāja, cenu datubāzes, autentifikācijas, Excel eksporta vai izvietotas tīmekļa lietotnes.

## Drošība
Publiskajā repozitorijā tikai kods un sintētiski testi. Klientu rasējumi, MLK cenu tabulas, piekļuves atslēgas un eksporta faili paliek ārpus Git.
